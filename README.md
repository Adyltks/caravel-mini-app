# Caravel Mini App

Telegram Mini App с каталогом услуг и Telegram-бот, который принимает заявки,
присылает их менеджеру и записывает в Google Таблицу.

```
webapp/   мини апп (статический сайт, без сборки)
bot/      бот + HTTP API для заявок (Node.js)
```

## Как это работает

1. Пользователь открывает мини апп из бота, выбирает услуги, заполняет заявку.
2. Мини апп отправляет заявку на `bot/` (`POST /api/order`) вместе с `initData`,
   бот проверяет подпись Telegram, чтобы заявки нельзя было подделать.
3. Бот присылает заявку в чат менеджера (`ADMIN_CHAT_ID`) и добавляет строку в Google Таблицу.
4. Менеджер отвечает клиенту прямо из своего чата: ответ (reply) на сообщение с заявкой
   уходит клиенту от имени бота.

## Запуск

### 1. Бот в Telegram
- В @BotFather: `/newbot`, получить `BOT_TOKEN`.
- Там же `/mybots → Bot Settings → Menu Button` и указать адрес мини аппа.

### 2. Мини апп
Папка `webapp/` публикуется на GitHub Pages автоматически (workflow в `.github/workflows/pages.yml`).
В настройках репозитория: Settings → Pages → Source: GitHub Actions.
В `webapp/config.js` указать адрес сервера бота (`CARAVEL_API`).

### 3. Сервер бота
```
cd bot
cp .env.example .env   # заполнить
npm install
npm start
```
Подходит любой хостинг с Node.js (Railway, Render, VPS). Нужен публичный HTTPS-адрес для `CARAVEL_API`.

Чтобы узнать `ADMIN_CHAT_ID`, напишите боту `/id` из нужного чата или группы.

### 4. Google Таблица (необязательно)
- В Google Cloud создать сервисный аккаунт, скачать JSON-ключ.
- Создать таблицу и дать доступ «Редактор» на email сервисного аккаунта.
- В `.env`: `GOOGLE_SHEET_ID` (из ссылки на таблицу) и `GOOGLE_SERVICE_ACCOUNT_JSON` (содержимое ключа одной строкой).

## База данных и админ-панель
Услуги, заявки и настройки хранятся в Supabase. Один раз выполнить `supabase/migration.sql`
в SQL Editor проекта, затем в `.env` бота указать `SUPABASE_URL` и `SUPABASE_SERVICE_KEY`.

Админ-панель открывается прямо в мини аппе (вкладка «Админ») у пользователей, чьи Telegram ID
перечислены в `ADMIN_IDS`. Там можно добавлять, менять и скрывать услуги, менять цены, смотреть
заявки и их статусы, менять название бренда, валюту и ссылку на менеджера.

Без Supabase бот работает из `webapp/services.js` и держит правки в памяти до перезапуска.
